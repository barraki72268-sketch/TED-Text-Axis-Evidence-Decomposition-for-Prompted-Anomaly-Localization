A high anomaly response can come from a defect
or a visually complex normal region.

Abstract

Prompted vision-language models can assign high anomaly scores to both true defects and visually complex normal regions. Stronger defect sensitivity therefore does not always produce reliable local rankings. We introduce Text-Axis Evidence Decomposition (TED), which compares each patch response with source defect patches and source normal patches that the host mistakes for anomalies. The comparison uses the host’s normal-to-anomaly text direction while keeping its backbone and prompts fixed.

T-TED uses the source evidence contrast directly without optimizing additional scoring parameters. C-TED learns a bounded residual from labeled source pairs and freezes it before target inference. Transfer experiments on frozen backbones and adapted hosts show improvements in many pixel localization settings, with gains that depend on the host and the extent of hard normal competition.

Defects and hard normal regions compete

Normal edges, reflections, textures, and object parts can receive scores close to those of real defects. We call these confusing normal patches hard false positives.

Compare evidence on the same text axis

Source masks identify defect patches, while high host scores identify confusing source normal patches. TED stores their visual features in two banks, then projects both banks and each query onto the current query’s text direction.

T-TED: direct evidence scoring

Compare the query’s axis coefficient with the source defect and hard normal coefficients. Average the evidence contrast across selected layers to obtain the local score.

r = qdef − λfp qfp

No additional scoring parameter optimization. Source labels are still required to construct the banks.

C-TED: source residual learning

Retain the adapted host score and use the evidence margin to learn a bounded residual from source defect and hard normal pairs.

sC = shost + γ tanh(a m̂ + b)

The host stays fixed during calibration. Residual parameters are frozen before target inference.

Both modes use labeled source evidence. Neither performs target-domain training.

Retain useful responses, reduce ambiguity

A strong response alone does not reveal whether it comes from a defect or a hard normal patch. The source evidence margin reorders those responses while retaining separation from ordinary normal regions.

Transfer results

Compare the baseline and TED with the same host checkpoint and processing settings. The source banks and correction are fixed before evaluating target datasets.

Source labels matter

Swapping or shuffling source labels reduces the gains under the same residual capacity and calibration budget. Correct defect and hard normal evidence matters beyond adding trainable parameters.
